Standalone player ↗

Run the engine somewhere with a GPU

  1. Start the Signalling Server from Epic's PixelStreamingInfrastructure (defaults to ws://localhost:8888).
  2. Launch your project in game mode: 
    UnrealEditor.exe MyGame.uproject -game \
  -PixelStreamingURL=ws://127.0.0.1:8888 \
  -RenderOffScreen -ResX=1920 -ResY=1080
  3. Paste the server URL above and press Connect.

This page is served over HTTPS, so a remote server must use wss://. Plain ws://localhost still works because browsers treat loopback as secure. Helper scripts live in unreal/ in the repo. No GPU handy? The Engine lab above runs a real UE4 HTML5/WebAssembly build with no streaming at all.

Why not Unreal?

Unreal needs a GPU workstation, a ~100 GB install and has no official HTML5 export since 4.24 — it cannot run inside a container like this one. The backdrop reproduces the look with three.js. Two real engines are wired up instead: Unreal Engine over Pixel Streaming and Godot 4 in WebAssembly.

Your keys stay yours

Settings are saved in this browser's localStorage. Translations travel directly from your tab to the provider you select — there is no backend to log them.

Broadcast-ready output

Cue timings are preserved to the millisecond, line breaks are kept, and exported SRT/VTT re-parse cleanly in players like VLC, mpv, Premiere and DaVinci Resolve.
